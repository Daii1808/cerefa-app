# 🐾 CEREFA App

Proyecto para la digitalización de formularios clínicos de CEREFA.

## 🛠️ Estructura del Proyecto
El proyecto utiliza una arquitectura limpia y segmentada dentro de la carpeta `src/`. 

*Nota: Verás algunos archivos `.gitkeep` dentro de las carpetas. No los borres; están ahí temporalmente para que Git no elimine las carpetas vacías en la nube.*
